# Historical app-rendered captures · 2026-10-17 · source `7222c4b`

This gallery records the October 17 source checkpoint and may show the former dormouse branding. It is retained as historical evidence. For the geometric mark and the native tree merged in `6c1cf6d`, see [the October 21 capture record](CAPTURE_2026-10-21_GEOMETRIC.md).

These eight PNGs were saved by the HungerStrike debug executable itself (Bevy's window screenshot, so each image is exactly the 1440 × 900 app window) on Neil's Windows 11 PC (NVIDIA GeForce RTX 4060, Vulkan), built from commit `7222c4b` on branch `hungerstrike-finish`. Each run used its own new, empty data folder and the app's synthetic capture route (`HUNGERSTRIKE_CAPTURE_DEMO`), so the header shows **SYNTHETIC TEST DATA**. No real receipt or personal inventory is shown.

**They are automated captures, not an interactive test.** Computer-use access to the HungerStrike window was requested and denied, so no mouse/keyboard click-through, file dialog or 3D picking was performed on this build.
