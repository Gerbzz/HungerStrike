The executable was built offline, locked, and single-job from source commit `74ca95366223cae4d946ca9a10250708e83d41c8` with the existing Cargo cache. Only `hungerstrike-core` and `hungerstrike-rust-desktop` compiled. The release build finished in 41.70 seconds; executable SHA-256 is `B98E62E7DE8604AF70C52B754F2FA149CA30AEEEEECD9884FA90BDA0C07D6DD7` (84,654,592 bytes). `cargo test --workspace --offline --locked -j 1` then passed 62 tests: 5 backup, 6 ledger, 4 projections, 6 receipt fixtures, 24 review regressions, and 17 desktop tests.

Each capture set `HUNGERSTRIKE_DATA_DIR` to a fresh isolated profile parent, `HUNGERSTRIKE_ASSETS_DIR` to this branch's `assets`, `HUNGERSTRIKE_CAPTURE_DEMO` to the named state, `HUNGERSTRIKE_CAPTURE_SIZE` to the stated dimensions, and `HUNGERSTRIKE_CAPTURE_PATH` to a new PNG. The process was stopped after each complete PNG was verified; natural app exit is not claimed. The capture stderr logs had no WARN, ERROR, or panic lines. All six PNGs were visually inspected: the light layout, stocked fridge and selected lot, receipt draft, meal cards, spending budgets, original dormouse tile, and authentic PWDS mark appeared. The header fit at 1280 x 720. At 1600 x 900 and 1280 x 720, the inspector's final explanatory text is below the viewport. `desktop/src/ui.rs` wraps the right inspector in a vertical `egui::ScrollArea` with an always-visible scrollbar. The 1600 x 1100 capture shows that full text at the top scroll position; no source or image-pixel changes were made to produce it.
