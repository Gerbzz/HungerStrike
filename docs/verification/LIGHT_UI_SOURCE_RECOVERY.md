# Light interface source recovery

This branch starts from public `main` at `ef8326417bb5c67baf8b8e75ba1269965b937bb3` and integrates the uncommitted Windows visual work from local `feature/hungerstrike-windows-slice` at `ea05f71dcc05d376740feb0d66944a57c1f0b2be`. The original local worktree, preview executables, review frames, and uncommitted files remain untouched. Public `main` had no intervening changes to the desktop or core source after the shared source checkpoint; its later commits changed artwork and documentation.

The recovery commit `74ca953` carries the light egui theme, refined storage and receipt layouts, stock details, meal and spending presentation, built-in synthetic capture states, scene selection, procedural kitchen and food geometry, and required local model/fixture assets. At that recovery checkpoint, `core/` accounting and persistence source was unchanged. The 16 model files retain their [Poly Haven and derivative provenance](../../assets/models/polyhaven/PROVENANCE.md). Follow-up work on this branch adds quantity-aware meal planning, a persistent local shopping list, explicit atomic cook actions, and compact Meals and Kitchen layouts. The corrected centered transparent [dormouse artwork](../../assets/branding/HungerStrike.png) and its provenance come exactly from public `main` commit `190742d`; the authentic [PWDS logo](../../assets/branding/PWDS-logo.png) is reserved for launch and About attribution rather than the working header.

The older dark README capture was built from `a55700a` and remains as labeled historical evidence. The local v4 light preview executable and frames were separately verified on October 11, but the local UI source was edited again on October 12. Those older images did not validate this integrated branch. The recovered `74ca953` source passed 62 workspace tests and produced six inspected light frames recorded in [capture provenance](../LIGHT_SCREENSHOT_PROVENANCE.md). Later commits added recipes and approved branding, corrected Kitchen sizing, and aligned the default Meals card highlight with its detail pane. The current `34405b7` source passed 71 offline workspace tests and produced new Kitchen, Meals, launch, About, shopping, and post-Cook frames with [exact provenance](../CURRENT_CAPTURE_PROVENANCE.md). Native mouse and keyboard interaction remains unverified.

For a bounded capture, use a new isolated `HUNGERSTRIKE_DATA_DIR` profile, the branch's local `assets` via `HUNGERSTRIKE_ASSETS_DIR`, one `HUNGERSTRIKE_CAPTURE_DEMO` state at a time, and new `HUNGERSTRIKE_CAPTURE_PATH` outputs. The app writes a SQLite file beneath the profile and a PNG at the selected path. Record the source commit, executable hash, asset hashes, fixture state, image hash, and visual limitations. Do not reuse the old v4 executable for a current-source claim.
